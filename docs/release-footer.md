
## Install

Download the `.dmg`, open it and drag **Leeway** to **Applications**. Then, in Applications, **right-click Leeway and choose Open** the first time; this build isn't notarized by Apple yet. Universal build, macOS 13 or later.

Verify the download with `gh attestation verify <file> --repo d0s1nt/leeway`, or against `SHA256SUMS.txt`.
